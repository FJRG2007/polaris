Open your Polaris

    Move your hosts

    To another computer or phone. Only the addresses and names travel, never a sign-in.

    Applies when Polaris restarts.

    Scan with the other device

    Open Polaris there, then Hosts > Scan QR.

    Too many hosts for one QR. Use Copy code or Export file instead.

    Scan a QR of hosts

    Hold the other device's QR up to the camera.

    Paste a code of hosts

    The code starts with polaris-hosts: and comes from Copy code on the other device.

    It only leaves this list. The host and your account stay as they are.

    Restart to apply

    Polaris uses the new setting once it restarts.
