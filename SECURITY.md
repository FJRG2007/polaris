# Reporting Security Issues

If you believe you have found a security vulnerability in **Polaris**, we encourage you to let us know right away. We will investigate all legitimate reports and do our best to quickly fix the problem.

Please do **not** open a public issue, pull request or discussion for it: that publishes the problem before a fix exists. Send us a private message from our [Discord server](https://tpe.li/dsc) instead.

A useful report includes:

- What the vulnerability is and what an attacker could do with it.
- The steps to reproduce it, or a proof of concept.
- The build it affects (**Admin > Updates & settings > Running build**) and the edition (full or limited).

## Supported versions

Polaris ships as a rolling release from `main`, installed from the Update button in Settings. Fixes land in the latest build only, so the supported version is the latest one: update before reporting, and check that the problem is still there.
