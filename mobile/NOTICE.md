# Fonts

The apps set their own screens in **IBM Plex Sans**, the face the dashboard uses, so a native screen reads as
Polaris. The Regular, Medium and SemiBold weights are converted from the dashboard's `woff2` files
(`dashboard/apps/web/src/fonts`) to TrueType, which Android and iOS load natively.
