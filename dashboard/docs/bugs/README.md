# Bugs worth writing down

Not a tracker. What lives here is the small number of faults that were expensive
to find and would be expensive to find again - where the symptom pointed
somewhere the cause was not, where a comment in the code asserted something that
turned out to be false, or where the thing that made it hard was that it worked
for days first.

One file each. What was seen, what it actually was, how it was proved, and what
now stops it coming back. A fix without the last of those is a fix that will be
undone by somebody reading the code and finding it arbitrary.

Nothing here names a real deployment: no public address, no host name, no
domain. An address in these pages is either a documentation range or a default
that is the same on every machine.
