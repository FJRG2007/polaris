# Fixture faces

The pictures in this folder are the profile photos of the invented people in the
README scenes, one per fixture account id (`fixtures/people.ts`). A person with
no file here is drawn with their initials, as an account with no photo is.

They are illustrations, not photos of anybody: the "Notionists" style by Zoish,
generated through DiceBear (https://www.dicebear.com/styles/notionists/) with the
seeds `polaris-<handle>`, then resized to 128 px WebP.
